# Snowfall

**Snowfall** is an American crime drama television series set in the early 1980s Los Angeles.  
It explores the first crack epidemic and its impact on the culture of the city.

---

## Main Characters

1. Franklin Saint  
2. Teddy McDonald  
3. Gustavo "El Oso" Zapata  
4. Lucia Villanueva

---

## Why I Like It

- Strong character development  
- Realistic storytelling  
- Intense and emotional scenes  
- Great soundtrack
